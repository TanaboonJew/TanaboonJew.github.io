Passenger Princess

A pre-release Cyberpunk 2077 passenger-meetup mod for So Mi, focused on defensive lifecycle handling, safe cleanup, seat checks, and a small extension API.

Pre-release 2026 LuaCyber Engine TweaksCodewareredscript

Current scope

Passenger Princess is a Cyberpunk 2077 meetup mod built around one current profile: So Mi. Invite her while V is on foot, let her follow, then stop an owned car with a free front-right seat and the mod can move the meetup into the passenger state.

The interesting part is lifecycle control rather than the invitation itself. Combat, death, scripted scenes, Photo Mode, fast travel or session loss, vehicle destruction, and manual dismissal all need to end the meetup cleanly. Occupied seats and unsupported vehicle situations are rejected rather than forcing the state through.

Engineering focus

  • Explicit meetup states and cleanup reasons. Summoned, following, mounting, seated, and dismissed transitions are observable instead of being implicit side effects.
  • A small extension surface. Other code can register profiles, summon or dismiss a meetup, inspect status, and subscribe to lifecycle events without modifying the core flow.
  • Story availability is configurable without rewriting quests. Invitations can use game journal state as a gate, while the mod avoids changing vanilla quest facts or Songbird records.
  • Voice integration is diagnostic-first. The profile references game voice-event names rather than packaging extracted audio. The in-game diagnostics distinguish a submitted native event from proof that audio was actually audible.
  • Release safety is conservative. Dynamic passengers are nonpersistent, and compatibility plus audible voice behavior remain in-game acceptance gates rather than being declared solved from code alone.

Release state

The repository is in pre-release development. Automated checks are useful evidence, but the project still treats its in-game acceptance matrix and voice verification as release gates.

Source repository is private. The case study is public.
